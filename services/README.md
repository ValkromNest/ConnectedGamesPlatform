# Applicazioni autonome (struttura obiettivo)

Questa directory ospiterà le applicazioni Yii2 estratte, ognuna con
composer.json, configurazione, entry point, migrazioni e Dockerfile propri:

- admin-console/
- matches-service/
- devices-service/
- darts-game-service/

Durante la Fase 2 l'app Yii2 alla root resta l'unico processo applicativo.
Le app autonome verranno create nelle rispettive fasi di estrazione, senza
copiare il monolite.
